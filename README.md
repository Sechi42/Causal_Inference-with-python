# Causal Inference with Python

Personal study repository for causal inference concepts, exercises, and experiments in Python.

## Contents

- `ch01/` through `ch11/`: chapter notes and exercises.
- `data/`: datasets used by the notebooks and scripts.
- `YSGA.ipynb`: applied experimentation notebook.
- `causal-inference-in-python-code/`: upstream companion material kept as a nested repository.

## Run locally

1. Create and activate a Python virtual environment.
2. Install the dependencies:

```bash
python -m pip install -r requirements.txt
```

3. Start Jupyter:

```bash
jupyter lab
```

The repository is study material. Review each notebook's data requirements before running it.
